Privacy Policy for World Clock Pro

Last updated: 2026-04-04

World Clock Pro is designed to work locally in your browser with minimal data use.

What data the extension stores

  • Clock list and settings (labels, timezones, ordering, display preferences)
  • Reminder settings (title, time, timezone, selected days, lead minutes, enabled state)
  • Optional profiles created by the user
  • Temporary selected time text for conversion flow
  • Temporary snooze metadata for reminder notifications

Where data is stored

  • chrome.storage.sync: user preferences that can sync with the same signed-in Chrome profile
  • chrome.storage.local: local-only data needed for reminder snooze behavior
  • chrome.storage.session: short-lived runtime/session helper values

Data collection and sharing

  • No analytics SDK is included.
  • No personal data is sold.
  • No data is sent to external servers for core functionality.
  • No account signup is required to use the extension.

Website access

When you explicitly use "Use page selection" or context-menu conversion, the extension reads selected text from the active tab to parse time text. This action is user-initiated and used only for conversion.

The extension does not continuously monitor browsing content.

Notifications

The extension uses Chrome notifications to show reminder alerts and optional snooze actions selected by the user.

Permissions usage summary

  • storage: save clocks/settings/reminders/profiles
  • alarms: update badge and check reminders
  • sidePanel: show extension UI in Chrome side panel
  • contextMenus: add convert-selected-time menu action
  • scripting + activeTab + tabs: fetch selected text from the active page on request
  • notifications: display reminder alerts

Changes to this policy

If privacy behavior changes, this policy will be updated with a new "Last updated" date.
