Tilawah Privacy Policy

Last updated: April 4, 2026

Tilawah is a Quran background audio extension. The extension is designed to run locally in the browser and only sends network requests needed to fetch Quran audio and text, and optional prayer time data.

What Data We Access

  • Extension settings (reciter, volume, playback preferences, reminder settings)
  • Playback state (current surah and ayah, progress position)
  • Optional bookmarks created by the user
  • Optional account email and sync token, if user signs in to a custom backend
  • Active tab URLs only when focus mode blocking is enabled (to block configured distracting domains)

What Data We Do Not Collect by Default

  • No personal profile is created by default.
  • No analytics or tracking SDK is included.
  • No browsing history is transmitted to third-party analytics providers.

External Services Used

  • Quran API and metadata: https://api.alquran.cloud
  • Quran audio CDN: https://cdn.islamic.network
  • Prayer times (optional reminders): https://api.aladhan.com

If backend sync is enabled by the user, data is sent only to the user-configured backend URL.

Storage

  • Local storage: settings, bookmarks, progress, and caches
  • Session storage: transient runtime state and URL cache
  • Optional browser sync storage: settings, progress, and bookmarks sync when selected

Data Sharing

Tilawah does not sell user data. Data is shared only with:

  • The APIs listed above to provide core functionality
  • An optional user-configured backend for account and sync

Security

  • Sensitive tokens are stored in extension storage for authenticated sync sessions.
  • Users can sign out and clear account data.

User Controls

Users can:

  • Disable reminders
  • Disable focus mode
  • Remove bookmarks
  • Sign out from backend sync
  • Uninstall the extension to remove extension data
