What to include in bug reports

  • Browser version (Chrome/Edge)
  • Extension version
  • Timezone setup (for example: Nepal, Lisbon, Adelaide, New York)
  • Clear reproduction steps
  • Screenshot or screen recording

Common notes

  • Use page selection works on normal websites, but not restricted pages like chrome:// and Chrome Web Store pages.
  • If badge time does not update, ensure at least one clock is active and badge mode is not Off.
  • Reminder notifications depend on browser notification permissions.
